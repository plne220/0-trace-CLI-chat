date of last change: 21/02/2026
current status: development (as in NOT FINISHED)

current features:
- messaging/file sharing
- single file setup
- Tor/tailscale support (cuz port forwarding is painful and this is meant to be secure)
- password protected
- TLS encrypted
- client anonymity
- network flexibility
- universal file support

- cool logo n' stuff
- more that i cant remember
